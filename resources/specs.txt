VARIABELEN BESTANDSTYPE, DOCUMENTTYPE, COVER, BOOKTITLE, AUTHOR en ISBN
---------------------------
TESTEDBYUSER: Vul bestandstype met de extensie van je bestand (.epub, .pdf et cetera)
TESTEDBYUSER: Vul documenttype voor markdown bestanden: 1) met type: uit de YAML frontmatter, als die er is. Voor markdown bestanden zonder YAML frontmatter, vul hem met de eerste occurrence van type: in de tekst. Voor alle andere bestanden blijft deze variabele leeg
TESTEDBYUSER: Vul voor ebooks de variabele booktitle met de boektitel
TESTEDBYUSER: Vul voor ebooks de variabele author met de author
TOBEBUILTNICETOHAVE: Gebruik voor mp3's de variabele booktitle met de naam van de track (zowel bij schrijven als bij lezen)
TOBEBUILTNICETOHAVE: Gebruik voor mp3's de variabele author met de naam van de artiest (zowel bij schrijven als bij lezen)
TESTEDBYUSER: Voor markdown files met YAML frontmatter: booktitle is de tekst achter "[booktitle]:". Als die regel er niet in staat, gebruik dan de tekst achter "[cover]:".
TESTEDBYUSER: Voor book covers uit markdown files zonder YAML frontmatter (mogelijk staan er meerdere boeken in 1 bestand): als er na een regel met "[cover]:" en voor de volgende regel met "[cover]:" een regel staat met "[booktitle]:", gebruik die waarde dan voor booktitle. Dus bij: [cover], [cover], [booktitle]: alleen bij de tweede cover hoort een booktitle, de eerste heeft er geen. Als er geen aparte "[booktitle]:"-regel is gevonden, vul booktitle dan met de tekst achter "[cover]:".
TESTEDBYUSER: Als er naast het boek een image staat met dezelfde naam + image extensie (bijv: book.pdf → book.pdf.jpg of book.epub.png), dan heeft dat image prioriteit boven de embedded cover. Ondersteunde formaten: .jpg, .jpeg, .png, .gif, .webp
TESTEDBYUSER: Vul voor ebooks de variabele [isbn] met het isbn-nummer.
TESTEDBYUSER: Vul voor markdown-bestanden variabele [isbn] vanuit de corresponderende regel in het markdownbestand. De logica is hetzelfde als voor [booktitle]. Dus: [cover], [cover], [booktitle], [isbn], [cover]: alleen voor het tweede boek is een isbn beschikbaar.
TESTEDBYUSER: Vul voor markdown files de variabele author met de waarde uit regel "[author]:". De logica is hetzelfde als voor booktitle.

TAGS ONDERHOUDEN
----------------
Tags zijn labels/categorieën die aan boeken gekoppeld kunnen worden, vergelijkbaar met Calibre's tags systeem. Tags kunnen gebruikt worden voor genres, leesstatus, collecties, etc.

=== FASE 1: Tags lezen ===
TESTEDBYUSER: Tags uit markdown YAML frontmatter lezen - formaat: "tags: [fiction, sci-fi]" of "tags:\n  - fiction\n  - sci-fi"
TESTEDBYUSER: Tags uit markdown inline lezen (multi-book format) - formaat: "[tags]: fiction, sci-fi" (configureerbare veldnaam)
TESTEDBYUSER: Tags uit EPUB metadata lezen - uit dc:subject elementen in OPF (was al geïmplementeerd)
TESTEDBYUSER: Tags uit MOBI/AZW/AZW3 lezen - via OPF sidecar file (zelfde naam, .opf extensie)
TESTEDBYUSER: Tags uit CBR lezen - via OPF sidecar file (RAR is niet leesbaar voor tags)
TESTEDBYUSER: Tags uit PDF lezen - uit keywords veld, of uit OPF sidecar als die bestaat (voor problematische PDFs)
TESTEDBYUSER: Tags opslaan in BookItem datastructuur als list[str]
TESTEDBYUSER: Tags normaliseren: trimmen, lege tags verwijderen, case behouden
